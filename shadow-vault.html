Project Overview

Vault is a standalone local file-locking utility designed to secure documents, images, and sensitive data directly on your computer. By reading local files and applying a custom byte-scrambling pipeline based on historical rotor cipher mechanics, Vault renders data completely unreadable without proper credentials. Packaged via PyInstaller using a --onefile and --noconsole configuration, it executes as a silent, self-contained background tool that can be run from a USB drive on any Windows system without requiring a Python installation.

Motivation & Core Purpose

Data Privacy on Shared Hardware: Built to conceal personal files, financial logs, and private code bases from casual observers, automated search indexers, or family members sharing the same desktop profile.

Key Project Goals:

  • Hands-on Cryptographic Exploration: Translating historical electromechanical cipher mechanics into automated software logic to bridge classical cryptography and modern Python execution.
  • Zero-Dependency Portability: Self-contained .exe distribution allows instant deployment across machines without installing Python libraries or environment setup.
  • Local File Locking: Provides a lightweight gatekeeper to immediately obscure files into encrypted byte blocks on disk.

Cryptographic Foundations: The Enigma Rotor Concept

1. Mechanical History & Rotor Stepping

The WWII German Enigma machine relied on rotating disc rotors with internal wiring to obscure plaintext characters. Crucially, with every keypress, the rightmost rotor stepped forward by one notch. This dynamic state movement ensured that typing identical consecutive characters produced completely different output bytes, breaking simple frequency analysis.

2. Digital Emulation & Reversibility

Vault mathematically translates mechanical brass rotors into programmatic state shifts applied to incoming binary file data:

  • Dynamic State Shifting: As files are processed block-by-block, substitution layers continuously rotate to simulate mechanical rotor stepping across byte indices.
  • Mathematical Reversibility: Mimicking the Enigma's reflector mechanics, the exact inverse mathematical operations are applied during decryption when supplied with the matching initial key state.

Protection Architecture & Security Features

  • Standalone Binary Packaging: Compiled via PyInstaller to obscure raw .py source code and prevent simple inspection via text editors.
  • Silent Background Execution: Configured with --noconsole flags for clean background operations during encryption/decryption cycles.
  • Data Integrity Handling: Built-in input validation prevents partial reads from dropping unreadable garbage data back onto the disk.
  • Portable USB Compatibility: Can be dropped directly into any directory or USB flash drive to lock down files on the go.
