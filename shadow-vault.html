What is Shadow Vault?

Shadow Vault is a password manager that runs entirely on your own computer — there's no server, no account, and no syncing over the internet. You set one master password, and everything else (saved logins, notes, Wi-Fi passwords, license keys) is encrypted and stored in a single local file. The app derives the actual encryption key from your master password using Argon2id, and encrypts your data with AES-256-GCM — the same kind of encryption used by modern password managers and secure messaging apps. On top of that, you can turn on an optional 6-digit authenticator code (SafeAuth) so opening the vault needs your phone as well as your password.

Why I Built This

I wanted a password manager I could fully trust and understand — one where my passwords never leave my own machine, and I know exactly how they're encrypted because I wrote the encryption myself. Most password managers ask you to trust a company's cloud servers; Shadow Vault removes that trust requirement entirely by keeping everything local.

Goals for the project:

  • Learn real cryptography, not toy examples: Implementing Argon2id key derivation and AES-GCM authenticated encryption properly — including salts, nonces, and integrity checks — instead of a simple XOR cipher.
  • Zero cloud dependency: The vault file lives on your disk. Nothing is uploaded anywhere, so there's no server to be breached and no account to lose access to.
  • Actually usable day-to-day: Beyond just storing passwords, it needed to cover the things I actually do — generating strong passwords, checking if a password has leaked, tracking login history, and encrypting random files when needed.

The Enigma Backup Engine

A side project inside the project

The main vault is protected by AES-256-GCM — that part doesn't need anything extra. But I also wanted a way to export the vault for offline backup that added a second, independent layer of obfuscation on top, just for fun and as a cryptography exercise. So I built a 9-rotor substitution cipher engine loosely inspired by the WWII Enigma machine: each "rotor" is a 256-byte substitution table, and data passes through all 9 in sequence, then back through their inverses to decrypt.

How it works

  • 9 fixed rotors: Each rotor is a deterministic byte-shuffling table, generated once from a seeded pseudo-random sequence.
  • Fully reversible: Decryption runs the same rotors in reverse order using their inverse tables, so the original backup can always be reconstructed exactly.
  • Backup-only, not the primary defense: This is an extra obfuscation layer for exported backups — the vault's real security always comes from AES-256-GCM + Argon2id.

What's Inside

  • AES-256-GCM encryption: The vault file is encrypted with a key derived from your master password using Argon2id — a memory-hard function designed to resist brute-force and GPU cracking attempts.
  • SafeAuth (optional 2FA): Turn on a 6-digit authenticator code, scanned once via QR, that's required alongside your master password at login.
  • Four entry types: Logins, secure notes, Wi-Fi credentials, and license/serial keys — all in one place.
  • Password generator & strength meter: Generate strong random passwords with adjustable length and character sets.
  • Breach checking (Have I Been Pwned): Checks your saved passwords against known data breaches, sending only a partial hash of the password — never the password itself.
  • Security Audit tab: Scans your whole vault at once and flags weak, reused, or breached passwords.
  • Audit Logs: A local log of logins, SafeAuth changes, and file encryption/decryption events, so you can see exactly when the vault was accessed.
  • Standalone file encryption: Encrypt or decrypt any file on your disk using the same AES-GCM scheme, independent of the vault.
  • Auto-lock & clipboard safety: The app locks itself after a period of inactivity, and anything copied to your clipboard clears automatically after a short timeout.

Technical Specifications

Component Specification
Language Python 3.x

Key Derivation Argon2id (memory-hard, GPU-resistant)

Two-Factor Auth TOTP (RFC 6238) via QR-based SafeAuth setup
Backup Layer Custom 9-rotor substitution cipher (offline export only)
Breach Checking Have I Been Pwned API (k-anonymity, hash-prefix only)
Supported OS Windows, Linux (macOS should work, untested)
Data Handled Logins, notes, Wi-Fi credentials, license keys, arbitrary files

How It Was Built

    1. Encryption core: Implemented Argon2id key derivation and AES-256-GCM encryption/decryption for the vault file, with a fresh random salt and nonce on every save. 2. Vault & entry management: Built the data model for the four entry types (logins, notes, Wi-Fi, licenses), and safe atomic file writes so the vault can't get corrupted mid-save. 3. Desktop UI: Built the whole interface in Tkinter — login screen, dashboard, entry forms, and a tabbed settings panel. 4. SafeAuth (2FA): Added TOTP-based two-factor authentication with QR code setup, verification, and the ability to reset or disable it later. 5. Security tooling: Added the password generator, strength checker, Have I Been Pwned breach lookup, the full security audit report, and a local audit log for login/security events. 6. Extras: Added standalone file encryption/decryption, the 9-rotor backup cipher for offline exports, session auto-lock, and clipboard auto-clear.
